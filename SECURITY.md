# Security Policy

We take security seriously and want to keep this project secure for everyone. This document details our supported versions and security reporting practices.

## Supported Versions

Only the latest release version on the `main` branch receives active security updates. 

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability within this repository, please do **NOT** open a public issue. Instead, report it through the following process:

1. **Email the Maintainer**: Send a description of the issue to the project owner.
2. **Details to Include**:
   - Description of the vulnerability and its potential impact.
   - Detailed steps to reproduce the issue (proof-of-concept code or scripts).
   - Any proposed remediation actions or patches.
3. **Response Timeline**: We will acknowledge receipt of your report within 48 hours and coordinate a fix or disclosure timeline.
